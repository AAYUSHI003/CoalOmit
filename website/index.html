What's inside

Everything you need to build greener AI

Three tightly integrated components that plug into your existing ML workflow — no new infrastructure required.

⚙️

comit-core — Measurement Engine

Uses PyTorch 2.x native FlopCounterMode to accurately count hardware FLOPs per inference. Calculates energy using per-precision constants across FP32, INT8, and INT4 models. Maps energy to monthly CO₂ using regional grid intensity for 35+ countries.

💻

comit-cli — Developer Tooling

A beautiful Rich-powered terminal CLI. Run comit run model.py and get a color-coded trade-off matrix in seconds. Export as Markdown, JSON, or terminal table. Compare any model across quantization strategies side by side.

🤖

comit-action — CI/CD Integration

A GitHub Action that automatically runs CoalOmit on every pull request and posts a full carbon comparison table as a PR comment — before code merges to main. Green AI engineering becomes a default part of your review process.

Simple by design

From model to CO₂ report in 3 steps

CoalOmit plugs into your existing PyTorch workflow. No new infrastructure. No API keys. Just results.

1

Install CoalOmit

Install via pip in seconds: pip install -e packages/comit-core packages/comit-cli. Works with any PyTorch 2.x model out of the box.

2

Point it at your model

Define a model and sample_input in a Python file. Then run: comit run model.py --region US --methods int8,int4

3

Get your carbon trade-off report

CoalOmit runs baseline + compressed benchmarks, calculates energy using FLOPs, and projects monthly CO₂ based on your deployment region's grid intensity. Choose table, markdown, or JSON output.
