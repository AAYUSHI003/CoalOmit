# Changelog

All notable changes to Carbon Lens will be documented in this file.

## [0.1.0] - 2026-08-03
### Added
- Initial release of `cac-core` engine (INT8 dynamic, INT4 weight-only quantization).
- FLOP-based energy estimation using PyTorch 2.x `FlopCounterMode`.
- Regional grid intensity data (35+ countries) & monthly CO2 projection.
- `cac-cli` with Rich terminal tables, Markdown, and JSON formatting.
- `cac-action` GitHub Action for pull request carbon comments.
